# 物理学里程碑实验速查 / Physics Landmark Experiments

把《薛定谔的猫：改变物理学的50个实验》蒸馏为一套可复用的**物理学实验速查 / 方法库**技能包。

- **覆盖**：物理学 50 项里程碑实验（`assets/experiments.md`），从恩培多克勒漏壶到希格斯玻色子。
- **统一骨架**：每条均为「背景假设 → 方法设计 → 关键结果 → 意义影响」四段，支持按年份 / 分支 / 研究者 / 主题检索与结构化蒸馏改写。
- **示例**：`examples/michelson.md` 提供完整条目样板（含"零结果"写法）。
- **元数据与校验**：`meta.json`、`VALIDATION.md`。

## 结构

```
physics-landmark-experiments/
├─ SKILL.md                     # 技能定义（何时使用/核心概念/工作流/规则/边界）
├─ assets/
│  └─ experiments.md            # 物理学 50 项里程碑实验速查表
├─ examples/
│  └─ michelson.md              # 完整条目示例（迈克尔逊-莫雷实验）
├─ meta.json                    # 技能元数据
└─ VALIDATION.md                # 发布前校验清单
```

## 使用

- 想快速了解某实验 → 在速查表中按名称/年份定位条目。
- 想按年份/分支/主题横向检索 → 使用速查表中的索引维度。
- 想把某实验改写为科普/讲义/脚本 → 以四段骨架为纲，用自己的语言重组。
